# Shadely brand

## The mark
A circle cut into bands that thin out toward the bottom. Tone comes from how much of the circle is filled, so it reads as a "shade" in one color, on any background, and at 16 px.

## Color system
Generated with Shadely's own engine from one base, `#5a50d2` (Shadely Indigo, stop 700). The bands step down the scale from dark to light.

| Role | Light backgrounds | Dark backgrounds |
|---|---|---|
| Bands, top to bottom | 900 `#3a328d`, 800 `#473cae`, 700 `#5a50d2`, 500 `#8083de`, 400 `#9ea2e1` | 300 `#c0c4e6`, 400 `#9ea2e1`, 500 `#8083de`, 600 `#6a68d7`, 700 `#5a50d2` |
| Wordmark (Ink / Paper) | `#27272e` | `#fafafb` |
| App icon | White mark on indigo 700 `#5a50d2` | same |

White text on indigo 700 has a contrast ratio of 5.98:1 (AA for body text). The one-color versions (black, white) must always stay available for print, stamps and embroidery.

## Files (`public/brand/`)
| File | Use |
|---|---|
| `shadely-logo.svg`, `-dark.svg` | Horizontal lockup, for light and dark backgrounds |
| `shadely-logo-stacked.svg`, `-dark.svg` | Stacked lockup for square spaces |
| `shadely-mark.svg`, `-dark.svg` | Symbol alone |
| `*-black.svg`, `*-white.svg` | One-color versions |
| `shadely-app-icon.svg` | Rounded app icon; `-full-bleed.svg` for stores that round it themselves |
| `shadely-favicon.svg` | Small-size cut: four heavier bands |
| `png/` | Transparent PNGs of all of the above, plus favicon 16, 32, 48, 180 and app icons 192, 512 |

Site icons are served from `src/app/`: `icon.svg`, `favicon.ico` (16, 32, 48) and `apple-icon.png` (180).

## Rules
- Wordmark is lowercase "shadely", set in Inter SemiBold and converted to outlines (no live text in the files).
- Clear space around the lockup: at least the height of the topmost band.
- Minimum size: symbol 16 px, horizontal lockup 80 px wide.
- Do not recolor the bands outside the steps above, add effects, or stretch the mark.
- Do not rely on the logo being cleared against existing marks. Run a trademark and reverse-image search before launch.

## Regenerating
The files are generated by a script that draws the bands and converts the wordmark to outlines. The PNGs are rendered from the SVGs. If the wordmark font changes, regenerate them all so they stay matched.
